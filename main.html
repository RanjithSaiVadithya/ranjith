Plans & Billing

Pricing model (example)

  • Free (trial 1 month) — limited connections, text chat, limited community join
  • Basic — ₹1,900 / 6 months — limited call minutes, up to 50 connections, full chat & community access
  • Pro — ₹3,900 / 12 months — higher limits, featured mentor listing

Plans are modeled in DB `plans` and `subscriptions`. Billing events stored to `transactions`.

Calls & Sessions

Functional flow

  1. Create session (scheduling) or start ad-hoc call → backend inserts into calls (call_uuid)
  2. Use media provider (Agora / Twilio / Jitsi) with call_uuid
  3. Record participants in call_participants; update durations on leave
  4. Update subscription_usage minutes for billing/enforcement

Calls, call_participants, sessions — included in schema data below (click FK links to navigate tables).

Business Report

Executive summary

SkillSwap: a peer-to-peer platform for focused skill exchange and mentorship. Targeting learners who need specific practical skills and mentors who want flexible monetization. Monetize via subscriptions, featured listing, and enterprise licensing.

Go-to-market & Growth

  • Launch pilot in targeted communities (DevOps, Web, ML)
  • Content marketing: mentor highlights, use-case success stories
  • Partnerships with colleges & freelancing groups
  • Referral credits & trial incentives

KPIs

  • MAU, paid conversion, average session minutes, ARPU, churn
  • Monitor mentor rating, time-to-match, retention of matched pairs

DDL & APIs

Quick API map

  • POST /api/register — register user
  • GET /api/users?skill=aws — search mentors by skill
  • POST /api/connection-requests — send connection request
  • POST /api/connections/{id}/accept — accept
  • POST /api/calls/start — create call & get call_uuid
  • POST /api/subscriptions/checkout — payment checkout

DDL snippets (plans, subscriptions, calls)

CREATE TABLE plans ( id INT AUTO_INCREMENT PRIMARY KEY, slug VARCHAR(64) UNIQUE, name VARCHAR(128), period_months TINYINT, price_cents BIGINT );
CREATE TABLE subscriptions ( id BIGINT AUTO_INCREMENT PRIMARY KEY, user_id BIGINT NOT NULL, plan_id INT NOT NULL, started_at TIMESTAMP NOT NULL, expires_at TIMESTAMP NOT NULL, status ENUM('active','cancelled','expired') DEFAULT 'active' );
CREATE TABLE calls ( id BIGINT AUTO_INCREMENT PRIMARY KEY, call_uuid CHAR(36) NOT NULL UNIQUE, initiated_by BIGINT NOT NULL, started_at TIMESTAMP NULL, ended_at TIMESTAMP NULL, duration_seconds INT NULL, call_type ENUM('audio','video') DEFAULT 'audio' );
