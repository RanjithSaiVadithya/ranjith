📊 Complete Schema Documentation & Flow Visualizations

This document combines full schema details, flowchart visualizations, and product mappings. Designed like an experienced architect would: modular, scalable, and future-proof for new features.

🧱 Layer 1 — Schema Documentation

Users & Skills

users
  - id (PK)
  - name, email (unique), password (hashed), profile_pic, bio
  - created_at, updated_at

skills
  - id (PK)
  - name, category, description

user_known_skills
  - id (PK)
  - user_id (FK → users.id)
  - skill_id (FK → skills.id)
  - level (enum: beginner, intermediate, expert)

user_learning_skills
  - id (PK)
  - user_id (FK → users.id)
  - skill_id (FK → skills.id)
  - progress (0-100%)

connections
  - id (PK)
  - user_id (FK → users.id)
  - connected_user_id (FK → users.id)
  - status (pending, accepted, blocked)

Community

communities
  - id (PK)
  - name, description
  - created_by (FK → users.id)

community_members
  - id (PK)
  - community_id (FK → communities.id)
  - user_id (FK → users.id)
  - role (member, mod, admin)

community_categories
  - id (PK)
  - community_id (FK → communities.id)
  - name

channels
  - id (PK)
  - category_id (FK → community_categories.id)
  - name, type (chat, voice)

messages
  - id (PK)
  - channel_id (FK → channels.id)
  - user_id (FK → users.id)
  - content, timestamp

calls
  - id (PK)
  - channel_id (FK → channels.id)
  - started_at, ended_at

Blogs

blog_posts
  - id (PK)
  - user_id (FK → users.id)
  - title, content
  - created_at

blog_comments
  - id (PK)
  - post_id (FK → blog_posts.id)
  - user_id (FK → users.id)
  - comment, created_at

🚀 Layer 3 — Product Feature Mapping

  • Users & Skills → LinkedIn-style Profiles: Users create profiles, list known/learning skills, connect with others. Future scope: endorsements, AI-skill recommendations.
  • Communities → Discord-style Groups: Users form communities, sub-categories, channels, chat/messages, and calls. Future scope: events, roles, monetization.
  • Blogs → Medium-style Content: Users publish posts, comment, interact. Future scope: tags, likes, shares, rich media embedding.
  • Master Integration: Users are the backbone; every feature ties back to them. Scalable for adding marketplace, jobs, or learning modules in future.
